Panduan Untuk Guru

Selamat datang di Ruang Guru Cendekia Aksara. Berikut panduan singkat:

  1. Pilih menu Aksi -> Login untuk masuk menggunakan akun Guru.
  2. Setelah login, Anda akan diarahkan ke Dashboard Guru untuk mengelola materi kelas.
  3. Buat Kelas baru untuk mendapatkan 6 Digit Kode Kelas Unik atau QR Code.
  4. Bagikan kode tersebut kepada siswa agar mereka bisa mengakses tugas dan materi spesifik kelas Anda.
Admin sekolah memegang kendali penuh atas pendaftaran akun guru baru.
